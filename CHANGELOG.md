# Changelog

## 0.2.0-beta (2026-10-04)

First public beta, tested on real Đình project pages (layout guideline pages and an icon cover page).

- Artboards, editable frame and artistic text, native shapes, curves, image fills and guides.
- Masks as Affinity mask layers, including masks built from component instances.
- Multiple fills as stacked shapes; linear, radial and angular (conical) gradients.
- Drop shadows, inner shadows and layer blur; extra and zero-blur shadows as shape copies.
- Stroke caps and joins, per-corner radius, whole-pixel rounding (`ROUND_TO_PIXEL`).
- Report file with plugin/script versions, missing fonts and simplified layers; `DEBUG` log for bug reports.
